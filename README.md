## 1 · Research — SciML & data assimilation

Completed MSc thesis: *Data-Driven Filtering Techniques for Turbulent Flow Models (A Lagrangian Data Assimilation Approach)* ([Scholaris](https://ucalgary.scholaris.ca/items/b4a3d3b9-4fbf-4d1e-8e1e-80c71c009825)). Hybrid EnKF / particle filter (WHERE) for barotropic quasi-geostrophic flow. Reconstructs Eulerian energy spectra from sparse Lagrangian drifters.

| Repo | |
|---|---|
| **[qg-lada-lab](https://github.com/ahmaddroobi99/qg-lada-lab)** | Public lab: spectral QG twin + localized EnKF in the browser, plus a committed Python solver (N = 32, XCOR 0.964). **[Live](https://qg-lada-lab.netlify.app)** |

Private thesis sources stay private (MATLAB / Python / TeX). They are not listed here.

```
Lagrangian drifters  →  QG barotropic model (q = ∇²ψ − μψ)
                     →  spectral Helmholtz inversion
                     →  localized stochastic EnKF  (+ optional EnKF–PF)
                     →  reconstructed Eulerian field, spectra, XCOR
```
